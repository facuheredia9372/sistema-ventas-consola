# Sistema de Gestión de Ventas y Stock

## Autor

Facundo Heredia

## Fecha

Junio 2026

## Descripción

Aplicación de consola desarrollada en JavaScript para gestionar productos, ventas y stock.

## Entidades

* Producto
* Venta
* Stock

## Funcionalidades

* Agregar productos.
* Listar productos.
* Registrar ventas.
* Consultar stock.

## Historias de Usuario

### US-01 Agregar productos

Como administrador quiero agregar productos para gestionar el inventario.

### US-02 Listar productos

Como administrador quiero listar productos para visualizar los artículos disponibles.

### US-03 Registrar ventas

Como administrador quiero registrar ventas para actualizar el stock automáticamente.

### US-04 Consultar stock

Como administrador quiero consultar el stock para conocer la cantidad disponible de cada producto.
